# 代码转动画 · Code → Animation

> 把你的代码跑成动画：粘贴一段 C / C++ / Python / Java 代码，逐行执行，数组、链表、树、图跟着一起变化。

这是一个**纯静态、零依赖、本地离线**的数据结构可视化网站。打开 `index.html` 就能用，不需要安装编译器、不需要起后端，代码也不会离开你的浏览器。

---

## 这是什么

学习数据结构时，最难受的不是看不懂代码，而是**脑子里想象不出内存里发生了什么**。

这个网站把代码执行过程拆成一步一步的动画：左边代码逐行高亮，右边同步画出数据结构的真实形态，侧边栏同时显示变量、调用栈、内存字节和输出。配合断点和单步，可以像在 IDE 里调试一样，看清每一次 `swap`、每一次入栈、每一个指针的指向。

适合：数据结构课程演示、算法过程讲解、自己排查「为什么这行结果不对」。

## 主要功能

- **多语言输入**：C / C++ 完整教学子集；Python、Java 支持循环、数组、函数等常用写法，自动识别语言，也可手动指定。
- **数据结构动画**：数组（格子 / 柱状 / 热力图）、单链表 / 双向链表 / 循环链表、栈与队列（顺序 / 链式）、二叉树、图（邻接矩阵 / 邻接表），支持环形与网格布局。
- **VS 式调试体验**：单击行号设断点、运行到光标、单步（F10）、跳出函数（Shift+F11）、播放 / 暂停、拖动进度条回看任意一步。
- **观察面板**：变量 Watch、调用栈、监视表达式（支持 `a[i]`、`n-1` 这类表达式）、模拟内存视图（按类型显示字节与小端序）、程序输出、标准输入（对应 `scanf` / `cin` / `input`）。
- **40+ 个现成示例**：排序（冒泡、插入、快排、选择、希尔、归并、堆）、查找、链表、栈队列、二叉树遍历、图的 BFS / DFS / Dijkstra / Prim、汉诺塔、约瑟夫环等，选中即看。
- **两套配色主题**：浅色取自梵高《盛开的杏花》，深色取自《星月夜》，磨砂玻璃质感，右下角可调节透明度。
- **完全不联网**：所有解析与执行都在浏览器里完成，源码不会上传到任何服务器。

## 怎么用

1. 打开 `index.html`（或直接双击）。
2. 粘贴代码，或点「导入文件」载入 `.c` / `.h` 文件（多文件会自动合并）。
3. 点右上角「▶ 生成动画」。
4. 点行号下断点，用 `F10` 单步、`Shift+F11` 跳出，看右侧数据结构与左侧变量如何同步变化。

### 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `→` / `F10` | 下一步 |
| `←` | 上一步 |
| `Shift+F11` | 跳出当前函数 |
| `Home` / `End` | 回到第一步 / 跳到结尾 |

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构、样式与主题（含梵高封面 SVG） |
| `engine.js` | C 子集的词法 / 语法解析与逐行执行引擎、数据结构快照 |
| `ui.js` | 编辑器高亮、可视化渲染、调试面板与交互 |
| `lang.js` | Python / Java → C 子集的转换层 |
| `examples.js` | 40+ 个内置示例代码 |
| `*-watermark.svg` / `*-wide.jpg` | 主题背景与水印素材 |

## 技术说明

- 原生 HTML / CSS / JavaScript，无构建步骤、无第三方依赖。
- 自带一个小型 C 解释器（tokenizer → parser → runner），在每一行执行后生成状态快照供回放。
- Python / Java 先被翻译成等价的 C 子集，再交给同一个引擎执行，因此动画与调试能力完全一致。
- 支持 `struct` / `typedef`、指针、多级指针、结构体数组、动态分配的模拟堆，以及 `scanf` / `cin` 形式的输入。

## 已知限制

- 语言支持面向教学场景：C / C++ 为常用子集，不是完整编译器；Python / Java 只覆盖常用语法。
- 不执行真实的系统调用或第三方库，标准输入由「输入」面板模拟提供。
- 递归深度、分配规模过大时会自动截断，以保证浏览器流畅。
